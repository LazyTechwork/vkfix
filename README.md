# VK Fix
VK Fix - скрипт, пришедший на замену VK Opt. Мы исправляем ВКонтакте в лучшую сторону. Мы сделали VK Fix максимально гибким, любой модуль можно включить или выключить.

## Инструкция по фото-стикерам
Фото-стикеры по умолчанию выключены. Чтобы включить перейдите в настройки расширения. Для этого нажмите на аватарку пользователя и там будет кнопка VK Fix. 

![image](https://github.com/user-attachments/assets/eea6ed18-a201-48b9-972e-89560d1eefe3)
![image](https://github.com/user-attachments/assets/2b9ea838-6ce4-481d-b0f6-5064200eddfb)

Не забудьте указать ID нужных альбомов - всплывающие подсказки работают только с ними. По умолчанию указан альбом "Сохранённые фото", у которого id -15.
Учтите, что подсказки пишутся в описании к фото в кавычках через запятую, пример: "подсказка1", "подсказка2".
За один запрос загружается до 1000 фото, поэтому старайтесь не использовать альбомы с большим количеством фото, чтобы не поймать капчу (которую пока мы никак не обрабатываем).

![image](https://github.com/user-attachments/assets/9e513179-bd90-4ea8-b546-209a60208a22)

## Инструкция по запуску в режиме разработки

В TamperMonkey создаём новый скрипт, пихаем туда следующий код.

```js
// ==UserScript==
// @name VK Fix
// @description Скрипт для улучшения интерфейса ВКонтакте
// @author Ivan Petrov (LazyTechwork)
// @license MIT
// @version 1.0.0
// @include https://vk.com/*
// @require file://C:/Work/Development/vkfix/dist/vkfix.user.js
// @grant GM_getValue
// @grant GM_setValue
// @grant GM_addStyle
// ==/UserScript==
```

Вместо `C:/Work/Development/vkfix` вставляем свой путь до этого проекта. Далее запускаем `npm run build` и всё готово, при новом билде скрипт будет автоматически браться из файла. 

Не забудьте дать TamperMonkey разрешение на работу с локальными файлами, это делается в настройках расширений Chrome.

Для автоматической сборки при изменениях используйте `npm start`
