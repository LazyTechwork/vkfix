### 2. Алгоритм Дамерау-Левенштейна

**Почему не обычный Левенштейн?**

Обычный Левенштейн считает "кот" → "кто" как 2 операции:
1. Удалить "о"
2. Вставить "о" в другое место

Дамерау-Левенштейн учитывает **транспозицию** (перестановку соседних символов) как **1 операцию**:
- "кот" → "кто" = 1 операция (транспозиция "о" и "т")
- "собака" → "сабака" = 1 операция (транспозиция "о" и "а")

Это идеально для опечаток!

### 3. Умное определение maxDistance

```typescript
getMaxDistance(wordLength: number): number {
  if (wordLength <= 2) return 0;  // "кот" - слишком короткое
  if (wordLength <= 4) return 1;  // "кот", "пес" - 1 опечатка
  if (wordLength <= 7) return 1;  // "собака" - 1 опечатка
  return 2;                       // "приветствую" - 2 опечатки
}
```

### 4. Интеграция в SearchEngine

Fuzzy поиск запускается **после** точных, префиксных и семантических совпадений:

```typescript
// 1. Точные совпадения
searchExactMatches()

// 2. Префиксные совпадения
searchPartialMatches()

// 3. Семантические совпадения
searchSemanticMatches()

// 4. Fuzzy совпадения (НОВОЕ!)
searchFuzzyMatches()
```

### 5. Расчет score для fuzzy

```typescript
calculateFuzzyScore(distance: number, wordLength: number): number {
  if (distance === 0) return 1.0;
  
  // Чем больше расстояние, тем меньше score
  const penalty = distance / wordLength;
  return Math.max(0, 1.0 - penalty);
}
```

## 🎓 Технические детали

### Алгоритм Дамерау-Левенштейна

Использует динамическое программирование с матрицей H:

```
Операции:
1. Замена: cost = 1
2. Вставка: cost = 1
3. Удаление: cost = 1
4. Транспозиция: cost = 1 (НОВОЕ!)

Пример:
"кот" → "кто"
к о т
к т о
  ↓ транспозиция "о" и "т" = 1 операция
```

### Почему это важно?

Большинство опечаток - это:
- **Транспозиция** (40%): "кот" → "кто", "привет" → "прив ет"
- **Замена** (30%): "кот" → "кит"
- **Вставка/удаление** (30%): "кот" → "крот"

Дамерау-Левенштейн оптимален для реальных опечаток!
